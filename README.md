## About

RyBridge helps independent professionals and small businesses find the marketing path that fits them — then builds the whole system with AI: positioning, content, a lead-generating website, and automated follow-up.

> Every small business deserves big-company marketing.
> 大公司的营销方法，每个小生意都值得拥有。

RyBridge 帮个人与中小企业找到适合自己的营销路径，再用 AI 把整套系统搭起来：定位、内容、获客网站和自动跟进。

## Features

- **Bilingual** — Chinese / English, one-click switch, remembers the visitor's choice
- **30-second checkup** — a 6-question quiz that suggests a next step and pre-fills the consultation form
- **Consultation form** — submissions go to Google Sheets with email notification (Google Apps Script), with spam protection and per-field validation
- **Responsive** — designed for desktop, tablet and phone
- **Accessible** — keyboard navigation, visible focus, reduced-motion support

## Tech

- Plain HTML, CSS and JavaScript — no framework, no build step
- Each page is a single self-contained file
- Hosted on GitHub Pages
- Fonts: Fraunces, Plus Jakarta Sans, Noto Serif SC, Noto Sans SC (Google Fonts)

## Updating the site

1. Edit or replace the HTML files.
2. Commit to the `main` branch.
3. GitHub Pages republishes automatically in 1–2 minutes.
